# 오디오 필요

이 폴더는 비어 있습니다.

이번 작업 요청은 "**롱폼 2편의 기존 음성**"을 재사용하라고 했지만, 이 세션에는
기존 롱폼 2편의 원본 음성 파일이 전달되지 않았고(업로드된 것은 완성된 숏츠
1~3편 mp4 3개뿐), 이 환경에는 TTS 생성 도구도 없습니다. 그래서 오디오는
만들지 않고 프로젝트/코드만 완성했습니다.

## 여기에 넣어야 하는 것

다음 중 하나를 `롱폼02_숏폼04.mp3` (또는 `.wav`)로 이 폴더에 넣어주세요.

1. **롱폼 2편 원본에서 이 구간(우연히 패스를 받은 사건 부분)만 잘라낸 음성**
   — "본인 INTP인데 ~ 연구 대상이 됐음"에 해당하는 원본 내레이션을 추출
2. **`../timeline.json`의 각 cue.voiceover / lines 텍스트를 그대로 새로
   녹음하거나 TTS로 생성한 음성** — 기존 숏츠 1~3편과 같은 보이스를 쓰면
   시리즈 톤이 유지됩니다.

## 넣은 다음

```bash
cd ..
node scripts/fit-timeline-to-audio.mjs   # timeline.json 타이밍을 실제 오디오 길이에 맞춰 재배분
./render/render.sh                        # 프레임 캡처 + mux -> output/롱폼02_숏폼04.mp4
```
