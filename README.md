# 커뮤니티 게시글형 숏츠 생성기

1080×1920 세로형(유튜브 Shorts) 화면에서, 한국 인터넷 커뮤니티 게시글을
읽는 느낌으로 텍스트가 순서대로 등장하고 자연스럽게 스크롤되다가,
게시글 아래 댓글까지 이어지는 영상 템플릿입니다.

외부 프레임워크 없이 순수 HTML / CSS / JavaScript로만 만들어졌고,
브라우저에서 `index.html`만 열면 바로 동작합니다.

## 파일 구조

```
index.html      화면 뼈대 (구조만 있고, 텍스트는 비어 있음)
style.css       디자인 & 애니메이션 (게시글/댓글 스타일, 등장 효과)
content.js      ✏️ 실제로 수정하는 파일 — 제목/본문/댓글/타이밍/영상 길이
script.js       content.js 데이터를 읽어 타이밍에 맞춰 화면에 뿌려주는 엔진
render/render.js  브라우저 화면을 실제 타이밍 그대로 녹화해 MP4로 변환하는 스크립트
package.json    `npm run render` 명령 정의
```

**새 숏츠를 만들 때는 `content.js`만 수정하면 됩니다.**
`index.html` / `style.css` / `script.js`는 그대로 재사용합니다.

## 1. 실행 방법

별도 설치나 빌드 없이 바로 실행할 수 있습니다.

- **가장 간단한 방법**: `index.html` 파일을 더블클릭해서 브라우저(크롬 권장)로 엽니다.
- 열자마자 화면 중앙에 1080×1920 비율의 프레임이 나타나고, 영상이 자동으로 재생을 시작합니다.
- 창 크기가 1080×1920보다 작아도 비율에 맞춰 축소되어 보이므로(레터박스),
  일반 모니터에서도 미리보기가 가능합니다.

> 일부 브라우저는 `file://`로 여는 로컬 스크립트 실행에 제약이 있을 수 있습니다.
> 문제가 있다면 아래처럼 간단한 로컬 서버로 열어도 됩니다.
>
> ```bash
> npx http-server .
> # 또는
> python3 -m http.server 8000
> ```
>
> 이후 브라우저에서 `http://localhost:8080` (또는 `:8000`)으로 접속합니다.

## 2. 글 내용 변경 방법

`content.js` 파일을 엽니다. 아래 값들만 텍스트로 바꿔주면 됩니다.

```js
title: {
  text: "본인 INTP인데 다른 INTP 만나면 피함", // 제목
  time: 0,
},

paragraphs: [
  { text: "근데 웃긴건 나도 인팁이라는 거임😂", time: 1.5, emphasis: "normal" },
  // ...
],
```

- `text` : 문단 내용입니다. 한 문단 안에서 줄을 바꾸고 싶으면 `\n`을 사용하세요.
  예) `"인팁이 싫어서 그런 건 아니고..\n약간 조마조마한거임"`
- `meta` 객체(게시판 이름, 닉네임, 작성 시간, 조회수)도 같은 방식으로 바꿀 수 있습니다.
- 문단 개수는 자유롭게 늘리거나 줄여도 됩니다. 배열이라서 `{ ... }` 블록을 복사/삭제하면 됩니다.

### 강조 여부 변경

각 문단의 `emphasis` 값으로 강조 정도를 정합니다.

| 값 | 효과 |
|---|---|
| `"normal"` | 기본 본문 크기 (기본값) |
| `"highlight"` | 다른 문장보다 크고 굵게 + 형광펜 밑줄 효과 |
| `"big"` | 아주 큰 글씨로 강조 (엔딩 문장 등에 사용) |

문단 안에서 특정 단어(예: "거울치료")만 한 번 더 세게 강조하고 싶다면
`strongWords` 배열에 그 단어를 적어주세요.

```js
{
  text: "동족애보다\n거울치료가 먼저 옴.",
  time: 23.3,
  emphasis: "big",
  strongWords: ["거울치료"], // 이 단어만 더 크고 진하게, 색이 들어간 하이라이트로 표시됨
},
```

## 3. 문장 등장시간 변경 방법

모든 등장 타이밍은 **영상 시작(0초)을 기준으로 한 "초" 단위**입니다.

- 문단마다 있는 `time` 값이 그 문단이 화면에 나타나는 시각입니다.
- 문단이 나타나면 화면이 자동으로 그 문단 쪽으로 스크롤됩니다.
- 문단 사이 간격을 늘리고 싶으면 `time` 값 차이를 크게, 빨리 넘기고 싶으면
  차이를 작게 주면 됩니다. (문장 길이에 따라 2~3.5초 정도 간격을 권장합니다)

```js
{ text: "근데 웃긴건 나도 인팁이라는 거임😂", time: 1.5, emphasis: "normal" },
{ text: "인팁이 싫어서 그런 건 아니고..\n약간 조마조마한거임", time: 3.7, emphasis: "normal" },
```

`commentsSectionTime` 값은 댓글창으로 화면이 넘어가는 시각입니다.
마지막 본문 문단이 충분히 보인 뒤의 시각으로 설정하세요.

## 4. 댓글 추가 방법

`content.js`의 `comments` 배열에 항목을 추가/삭제하면 됩니다.

```js
comments: [
  { text: "본인이 본인 싫어하는 거 아님?", time: 27.3, nickname: "ㅇㅇ", likes: 128 },
  { text: "인팁 일반화를 멈춰주세요.", time: 28.2, nickname: "ㅇㅇ", likes: 64 },
  { text: "나도 근데 인팁인데 저런 인팁 싫음", time: 29.1, nickname: "ㅇㅇ", likes: 231 },
  // 댓글을 더 추가하려면 아래처럼 블록을 복사해서 붙여넣으세요.
  // { text: "새 댓글 내용", time: 30.0, nickname: "ㅇㅇ", likes: 0 },
],
```

- 댓글끼리 `time` 간격을 0.7~1초 정도로 주면 요청하신 것처럼 하나씩 등장하는 느낌이 납니다.
- `nickname`, `likes`는 선택 사항이며, 생략하면 기본 닉네임(`ㅇㅇ`)으로 표시되거나
  좋아요 숫자가 표시되지 않습니다.

## 5. 화면 녹화 방법

### 방법 A. OBS Studio "브라우저 소스" (가장 깔끔하고 추천하는 방법)

1. OBS에서 소스 추가 → **브라우저(Browser Source)** 선택
2. URL에 `index.html`의 로컬 경로를 입력하되, 끝에 `?clean=1`을 붙입니다.
   - 예) `file:///Users/이름/intp-shorts/index.html?clean=1`
   - `?clean=1`을 붙이면 편집용 안내 문구와 "다시 재생" 버튼이 자동으로 숨겨집니다.
3. 너비 **1080**, 높이 **1920**으로 설정합니다.
   → 이렇게 하면 크롭 없이 정확히 1080×1920 화면이 그대로 캡처됩니다.
4. OBS에서 해당 소스를 녹화(또는 방송)하면 완성입니다.

### 방법 B. 브라우저 창을 그대로 화면 녹화

1. 브라우저에서 `index.html?clean=1`로 접속합니다. (컨트롤 UI가 숨겨집니다)
2. 크롬 개발자도구(F12) → 기기 툴바 켜기 → 사용자 지정 크기를 **1080×1920**, 배율 100%로 설정하면
   레터박스(여백) 없이 프레임이 창에 꽉 차게 됩니다.
3. QuickTime(macOS), ShareX/OBS(Windows), 화면 녹화 앱 등으로 해당 창만 녹화합니다.
4. 레터박스가 남아있다면 녹화 후 영상 편집 툴(예: CapCut, 프리미어)에서 1080×1920으로 크롭하면 됩니다.

### 팁

- 페이지를 새로고침하면 항상 처음부터(0초) 다시 재생됩니다.
- 녹화 시작 직후 바로 새로고침하고, `content.js`의 `totalDuration`(기본 33초) + 1~2초 정도
  여유를 두고 녹화를 종료하면 끝부분이 잘리지 않습니다.
- 화면 우측 하단의 "⟲ 다시 재생" 버튼과 타이머는 편집 확인용이며, `?clean=1`로 접속하면 보이지 않습니다.

## 6. MP4로 자동 출력하기 (`npm run render`)

수동으로 화면을 녹화하지 않아도, 명령어 한 번으로 `index.html?clean=1` 화면을
**실제 재생 속도 그대로** 녹화해서 1080×1920 / 30fps MP4 파일로 만들어주는
스크립트가 포함되어 있습니다. (`render/render.js`)

### 사전 준비 (최초 1회)

1. [Node.js](https://nodejs.org)가 설치되어 있어야 합니다.
2. [ffmpeg](https://ffmpeg.org)가 설치되어 있어야 합니다.
   - macOS: `brew install ffmpeg`
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - Windows: [공식 빌드](https://ffmpeg.org/download.html) 다운로드 후 PATH에 등록
3. 프로젝트 폴더에서 의존성을 설치합니다.
   ```bash
   npm install
   npx playwright install chromium
   ```

### 실행

```bash
npm run render
```

- `content.js`의 `totalDuration` 값을 자동으로 읽어, 그 길이(+약 1.5초 여유)만큼
  브라우저를 실제로 재생시키면서 녹화합니다.
- 기존 CSS/JS 애니메이션과 타이밍은 전혀 건드리지 않고, 화면에 보이는 그대로 캡처합니다.
- 녹화 화면은 항상 `?clean=1` 상태(편집용 UI 없이 순수 결과 화면)로 캡처됩니다.
- 완료되면 아래 경로에 최종 영상이 생성됩니다.
  ```
  output/shorts.mp4   (1080x1920, 30fps, H.264 mp4)
  ```
- `content.js`만 수정하고 다시 `npm run render`를 실행하면, 새 내용으로 MP4가 다시 만들어집니다.

## 7. 다음 숏츠를 만드는 가장 빠른 방법

1. `content.js` 파일 하나만 열어서 아래 항목을 새 글 내용으로 교체합니다.
   - `title.text` (제목)
   - `paragraphs` 배열 (본문 문단들, 각 문단의 `text` / `time` / `emphasis`)
   - `comments` 배열 (댓글들, 각 댓글의 `text` / `time`)
   - `totalDuration` (전체 영상 길이)
2. `index.html`을 새로고침해서 타이밍이 자연스러운지 눈으로 확인합니다.
   (문단이 너무 빨리/늦게 나오면 `time` 값만 조정하면 됩니다)
3. 마음에 들면 `npm run render`로 바로 MP4를 뽑거나, 위 "화면 녹화 방법"대로 직접 녹화합니다.

즉, **`content.js`만 갈아끼우면 코드 구조를 전혀 건드리지 않고 새로운 숏츠를 계속 찍어낼 수 있습니다.**
